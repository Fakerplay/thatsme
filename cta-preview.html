Design Anatomy: Why the Previous Arrows Looked Wrong

✕ The Problem: Raw Unicode Character (↗)
↗ Rendered via OS font fallback

System Unicode glyphs vary drastically across Windows, Mac, and mobile. On Windows, they render with blunt, clunky arrowheads, inconsistent stroke weight that mismatches the font, and uneven vertical baselines that make buttons look cheap.

✓ The Solution: Optical 1.6px SVG Vector
Mathematically aligned vector

Rendered with currentColor and stroke-width: 1.6, calibrated to Geist Mono's exact cap height. Moves with smooth CSS transforms without layout recalculation.
